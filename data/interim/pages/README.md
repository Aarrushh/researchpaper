# data/interim/pages/

- **What belongs here:** rendered page images, regenerable from config plus text plus font.
- **Where it comes from:** `mrr.render.render_page`.
- **Licence:** inherits the font licence and the text's public-domain status.
- **Committed:** no. `make clean-interim` deletes them.
- **Rule:** anything here can be deleted and regenerated at any time.
