# notebooks/

Naming follows Cookiecutter Data Science: `<major>.<minor>-<short-description>.ipynb`, for example `1.0-pilot-exploration.ipynb`.

- Notebooks are for looking, not for results.
- Anything the paper uses must come from `scripts/` and land in `results/` or `reports/`.
- Clear outputs before committing if they contain rendered pages.
