# Reading notes

Create one file per paper, named after its BibTeX key in `references/references.bib`. Copy this template:

```
# <bibkey>: <title as printed on the paper>

- arXiv / DOI:
- Read by:            Date:

## Question
What problem does the paper address?

## Method
What did they do, in three lines or fewer?

## Key number
The one number we might cite, with page and table/figure reference.

## What it does not do
The gap our work fills relative to this paper.

## How we cite it
The exact claim we will attribute to it. Add the same claim as a row in references/citations.md.
```
